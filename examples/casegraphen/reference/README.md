# CaseGraphen Reference Workflow

This directory retains the deterministic workflow graph and reasoning report
fixtures used by HigherGraphen tests after the CaseGraphen extraction.

The JSON fixtures intentionally preserve their original embedded repository
paths as historical provenance. Current CaseGraphen schemas, runnable examples,
CLI tests, and operator documentation live in
[`CAPHTECH/casegraphen`](https://github.com/CAPHTECH/casegraphen).
